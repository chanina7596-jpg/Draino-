DRAINO WEBSITE - UPLOAD INSTRUCTIONS

1. Back up the current website.
2. Upload every file and the assets folder into the hosting public root (usually public_html).
3. Confirm index.html loads at https://draino24.com.
4. Keep SSL active and redirect HTTP/www to the preferred HTTPS version.
5. Submit https://draino24.com/sitemap.xml in Google Search Console.
6. Replace the three homepage review placeholders with real customer reviews before publishing.
7. Submit the service-request form once after publishing. FormSubmit will email
   service@draino24.com an activation link. Click that link to begin receiving leads.
8. Send a second test request and confirm that it arrives with the customer's name,
   phone, email, town/address, requested service, and problem details.
9. Test all phone and WhatsApp links on a mobile phone.

This is a static HTML website. The service-request form is delivered to
service@draino24.com through FormSubmit and redirects customers to thank-you.html.
